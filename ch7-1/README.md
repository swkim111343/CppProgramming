## C++ 챕터 7-1
## 실습과제1
1. 프렌드 함수가 왜 필요한가?
    - 클래스 외부 함수가 내부 데이터에 접근해야 할 때 일반 함수는 클래스의 private 데이터에 접근할 수 없다.
    - 하지만 어떤 기능은 클래스 외부 함수 형태로 구현하는 것이 더 자연스럽기 때문

2. 객체 지향형 언어의 특징 중의 하나인 다형성의 의미와 종류를 조사하시오
    - 다형성(Polymorphism) : 하나의 인터페이스(함수, 연산자 등)가 여러 형태로 동작하는 성질을 의미
    - 즉, 같은 이름의 함수나 연산자가 상황에 따라 다르게 동작하는 것이다.

    - 컴파일 시간 다형성 (정적 다형성)
    - 실행 시간 다형성 (동적 다형성)
