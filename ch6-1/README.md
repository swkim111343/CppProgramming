## C++ 챕터 6-1
## 실습과제1
1. C언어와 C++언어에서 컴파일러가 호출할 함수를 결정하는 방식의 차이를 설명하라
    - C언어의 함수 결정 방식 : C에서는 함수 이름이 같으면 다시 정의할 수 없으므로, 컴파일러는 사실상 함수 이름 자체로 호출 대상을 찾는다. 
    즉, 같은 이름의 함수가 여러 개 존재하지 않기 때문에 “어느 함수를 부를지”를 복잡하게 판단할 필요가 거의 없다.
    
    - C++의 함수 결정 방식 : C++에서는 함수 오버로딩이 가능해서, 같은 이름의 함수가 여러 개 있을 수 있다.
    이때 컴파일러는 호출 시점에 매개변수의 개수, 타입, const 여부, 참조 여부 등을 보고 가장 맞는 함수를 선택한다.
